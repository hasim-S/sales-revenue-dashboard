# Sales & Revenue Analysis Dashboard

Interactive dashboard built for the Thiranex Data Analyst internship task.

## What it does
- Imports sales data (`sales_data.csv`) covering 10 products across 4 regions over 12 months
- Tracks KPIs: total revenue, units sold, average order value, leading category
- Visualizes monthly revenue trend, revenue by category, and top-performing products
- Filters/slicers: region, category, and a month-range slider — all charts and the KPI row update live

## Files
- `index.html` — the dashboard (open directly in a browser, no build step needed)
- `sales_data.csv` — sample sales dataset used by the dashboard

## Tech
Vanilla HTML/CSS/JS + Chart.js (loaded via CDN, no install required).

## Run it
Just open `index.html` in any browser, or enable GitHub Pages on this repo and share the live link.
